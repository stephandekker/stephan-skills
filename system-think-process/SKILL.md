Interview me relentlessly about every aspect of a process until we reach a shared understanding about it, so you can generate a swimlane diagram in Mermaid format in .md file. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one. 

Apply system thinking to the process, considering how each part interacts with the others and the overall goals. Ask clarifying questions to ensure we are on the same page and to uncover any hidden assumptions or constraints.

Please forget everything you know about the domain and define a (new) process from the ground up. Start questioning from the intiator and build out the process from there.

Ask one question at a time, and wait for my answer before asking the next one. If I mention a specific part of the process, ask follow-up questions to understand it better.

If a question can be answered by exploring the codebase, explore the codebase instead.
